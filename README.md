# AI Car Deal Sourcing and Auto-Texting

This repo is a project brief, not the client's private code. It records what the buyer asked for so the build can be scoped against a real paid post.

## What this repo is about

A used-car dealership owner posted a paid project to automatically find vehicle deals online, evaluate them, and contact sellers quickly. Budget on the post was $25–$50/hour, under 30 hours a week, 1–3 months, with long-term intent. More than 50 proposals.

## Source post

https://www.upwork.com/freelance-jobs/apply/Car-Deal-Sourcing-Auto-Texting-System_~022044268320760009230/

## Client requirements

- Collect public marketplace listings: year, make, model, mileage, price, listing details, and seller contact when available.
- Score deals by price versus market value, mileage, and condition. Rule-based or AI scoring is acceptable.
- Push leads into an existing CRM with stages: New Lead, Contacted, Negotiation, Acquired.
- Automated SMS through an API for the first outreach to sellers.
- Open to continued work if the first build is solid.
- Proposal must include relevant work, proposed tech stack, and the build approach.
